# assets/img — 이미지 폴더

여기에 사진·화면 캡처·배너 이미지를 넣으세요.
파일 이름은 `assets/js/data.js` 의 `src` 값과 **똑같이** 맞춰야 합니다.
(대소문자 구분함. 이름이 다르면 사이트에 "이미지를 넣어주세요" 안내 상자가 뜹니다.)

---

「월별 디벗 업무 요약」 페이지에서 쓰는 배너입니다. 아래 이름 그대로 저장하세요.

|---|---|
| `month-01.png` | 1월 — 기기 수량 체크 및 충전함 전원 제거 및 보관 |
| `month-02.png` | 2월 — 신학기 준비, 교사 디벗 배부, 소프트웨어 학운위 통과, 학생 계정 학년 올리미 |
| `month-03.png` | 3월 — 디벗 교육, 기기 배부 |
| `month-04.png` | 4월 — 기기 점검, 라벨링 작업 |
| `month-05.png` | 5월 — 기기배부, 1학년 디벗 교육 |
| `month-06.png` | 6월 — 3학년 디벗 기기 중간 점검 |
| `month-07.png` | 7월 — 1,2학년 기기 점검(분실, 파손) |
| `month-08.png` | 8월 — 3학년 양품화 기기 점검, 2학기 준비 |
| `month-09.png` | 9월 — 튜터 방문 일정 확인, 디벗 담당자 연수 참여 |

- 확장자가 `.jpg` 라면 `data.js` 의 경로도 `.jpg` 로 바꿔주세요.
- 가로세로 비율은 **16:9 정도**가 가장 잘 맞습니다.
- 웹용이므로 가로 **1600px 이하**로 줄여 저장하면 사이트가 훨씬 빠릅니다.
